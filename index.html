Hyderabad Urban Observatory

Open spatial data

Open layers for Hyderabad and the HMDA region: boundaries, transport, amenities, housing, water, 2031 land-use plans, historical maps and imagery, built-up growth 1985–2023, building heights and elevation. Published in dated releases that never change, in formats that open directly in QGIS, GeoLibre, DuckDB, Python and web maps.

Use it

QGISAdd Vector Layer → Protocol HTTP(S) → a .parquet URL; rasters: download the .pmtiles
GeoLibreAdd Data → URL → a .parquet or .pmtiles URL
DuckDBSELECT * FROM read_parquet('…/vector/ghmc_wards_2026.parquet')
Pythongpd.read_parquet('…/vector/ghmc_wards_2026.parquet')
